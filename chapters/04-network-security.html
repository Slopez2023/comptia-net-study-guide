  • Encryption: data in transit (TLS, IPSec, SSH) and data at rest (disk or database encryption).
  • PKI = a certificate authority signs certificates that browsers trust. A self-signed certificate isn't trusted by default and triggers browser warnings.
  • MFA = two or more different factor types: something you know, have, or are (plus somewhere you are). SSO = log in once and reach many apps. SAML = the SSO standard for web apps. LDAP (389/636) = directory lookups. Time-based = logins allowed only during set hours, or TOTP codes.
  • Least privilege = only the access needed. RBAC = permissions are assigned to roles, and users get roles.
  • Geofencing = allow or deny based on location. Honeypot / honeynet = a decoy that lures attackers so you can study them.
  • Compliance: PCI DSS = card payments. GDPR = EU personal data. Data locality = data must stay in a given country.
  • Segment IoT/IIoT, SCADA/ICS/OT, guest and BYOD devices onto their own VLANs or zones. They're hard to patch or untrusted.
Watch for
  • Admins logging into switches with per-command control → TACACS+. Wi-Fi users authenticating against AD → RADIUS.
  • A password plus a PIN is not MFA. Both are "something you know".

Watch for

"Users got 10.0.0.x addresses with the wrong gateway" → rogue DHCP → DHCP snooping. "Switch is acting like a hub" → MAC flooding → port security.

Harden devices, control who can plug in (NAC), write ACLs in the right order, and place servers in the right zone.

  • Hardening: disable unused ports (shut them down and put them in an unused VLAN), disable unused services (Telnet, HTTP), change default passwords, patch firmware.
  • NAC: 802.1X = port-based authentication (supplicant → authenticator switch/AP → RADIUS server). Port security = limit or learn MACs per port. MAC filtering = an allow list of MACs (easy to spoof, weak on its own).
  • ACLs are read top-down, and the first match wins. Put specific rules first. Every ACL ends with an implicit deny all.
  • URL filtering = block sites by address or category. Content filtering = block by what the content contains (malware, file types).
  • Key management = generate, store, rotate and revoke encryption keys safely.
Watch for

A PBQ shows a firewall rule list where traffic is wrongly blocked. Look for a broad deny above the specific allow, and move the allow up.
