Explain how a router picks a route (longest prefix → AD → metric), compare OSPF/EIGRP/BGP, and know NAT vs PAT and FHRP.

  1. Longest prefix wins
    A /27 route beats a /24 route that also matches. Most specific first.
  2. Lowest AD wins
    If the prefixes tie, use the most trusted source (administrative distance).
  3. Lowest metric wins
    Within the same protocol, the best cost or path.

"0-1-20-90-110-120": Connected, Static, eBGP, EIGRP, OSPF, RIP. Lower = more trusted.

  • NAT translates private ↔ public IPs. PAT (NAT overload) maps many inside hosts to one public IP using different source ports. This is what your home router does.
  • FHRP (HSRP, VRRP, GLBP): two routers share one virtual IP (VIP) that hosts use as their default gateway. If the active router fails, the standby takes over the VIP.
  • Subinterfaces (for example g0/0.10) let one physical router port serve several VLANs over a trunk. This is "router on a stick".
  • Default route = 0.0.0.0/0, the "gateway of last resort" used when nothing more specific matches.
Watch for
  • Routing between companies or ISPs → BGP. Large enterprise open standard → OSPF.
  • "Hosts lose access when the gateway router fails" → configure an FHRP with a VIP.

  • VLAN = a separate broadcast domain on the same switch. SVI = a virtual L3 interface for a VLAN, used for inter-VLAN routing or switch management.
  • Native VLAN = the one VLAN sent untagged over a trunk. It must match on both ends. Change it from VLAN 1 to prevent VLAN hopping.
  • Voice VLAN = the phone tags its own traffic into the voice VLAN while the PC behind it uses the data VLAN on the same port.
  • Link aggregation (LACP / 802.3ad) bundles ports into one logical link for more bandwidth and redundancy.
  • STP (802.1D) elects a root bridge (lowest bridge ID = priority + MAC). Root ports point toward the root. Designated ports forward on each segment. Everything else is blocked. RSTP (802.1w) converges faster.
  • Jumbo frames = MTU above 1500 (usually 9000) for storage and data center traffic. Every device on the path must support it.
  • Speed/duplex must match. A duplex mismatch shows up as late collisions and slow performance.
Watch for
  • Broadcast storm or MAC table flapping → a loop, so STP is the answer.
  • The "VLAN database" is where VLANs are created. An access port assigned to the wrong VLAN gets the wrong subnet.

Choose bands, channels, encryption, authentication, antennas and AP types for a wireless scenario.

6 GHzShortestFastest, lots of clean spectrumWi-Fi 6E / 7, WPA3 required
  • Channel width: wider (80/160 MHz) = faster but fewer channels and more interference. In dense areas use 20/40 MHz.
  • 802.11h = regulatory: DFS (dynamic frequency selection) and TPC (transmit power control) in 5 GHz. Band steering pushes dual-band clients to 5/6 GHz.
  • SSID = network name. BSSID = one AP radio's MAC. ESSID = the same SSID across many APs (roaming).
  • Network types: infrastructure (clients ↔ AP), ad hoc (client ↔ client, no AP), mesh (APs relay to each other), point-to-point (bridge between buildings).
  • WPA2 = AES-CCMP. WPA3 = SAE replaces the old pre-shared key exchange, so captured handshakes can't be cracked offline. It also adds a stronger 192-bit enterprise mode. PSK = one shared password. Enterprise = 802.1X + RADIUS, a login per user.
  • Captive portal = a guest web login or terms page before access.
  • Omnidirectional antenna = covers all around (office ceiling). Directional (Yagi, parabolic) = focused beam, long range (building to building).
  • Autonomous AP = configured one at a time. Lightweight AP = managed by a wireless LAN controller (WLC).
Watch for

A company that needs individual Wi-Fi logins and the ability to revoke them → WPA3-Enterprise / 802.1X, not PSK. Most secure choice → WPA3. Never pick WEP or TKIP.

Plan a wiring closet: MDF vs IDF, racks and airflow, patch panels, power (UPS/PDU), and environmental controls.

MDFMain distribution frame. The central room where the ISP enters and the core equipment lives
IDFIntermediate distribution frame. Wiring closets on each floor or wing that connect back to the MDF
Rack units1U = 1.75 in. A standard rack is 42U and 19 in wide. Lockable racks for physical security
AirflowMatch port-side intake/exhaust to the hot aisle / cold aisle layout. Fronts face the cold aisle
Patch panelPermanent cable runs end here. Short patch cables go to the switch. Fiber uses a fiber distribution panel
UPSBattery backup for short outages and a clean shutdown. A generator handles long ones
PDUA rack power strip. Managed PDUs can be monitored and outlets switched remotely
Power loadAdd up device watts. Keep under ~80% of circuit and UPS capacity. Check the voltage (120 / 208 / 240 V)
  • Temperature: cool and steady (about 64–80 °F / 18–27 °C). Humidity: too low = static discharge (ESD), too high = condensation and corrosion. Aim for about 40–60%.
  • Fire suppression: water sprinklers damage equipment. Data centers use clean agent / gas systems (FM-200, inert gas) or a pre-action dry pipe that fills with water only after the alarm.
Watch for

"Server room needs fire suppression that won't damage equipment" → a clean agent (gas) system, not a wet pipe. Frequent static shocks → humidity is too low.
