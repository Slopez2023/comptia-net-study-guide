Name the 7 OSI layers in order, and place any device, protocol or data unit on its layer.

7ApplicationHTTP, DNS, SMTP, SSH: what the app speaks
6PresentationEncryption, encoding, compression (TLS* / SSL)
5SessionStart, maintain and end sessions (control/data)
4TransportTCP / UDP · ports · segments / datagrams
3NetworkIP · routers · packets
2Data linkMAC · switches · frames
1PhysicalCables, signals, hubs · bits
Mnemonic

Top to bottom (7→1): All People Seem To Need Data Processing.
Bottom to top (1→7): Please Do Not Throw Sausage Pizza Away.

  • Encapsulation: going down the stack, each layer wraps the data in its own header. Data → segment (L4 + port) → packet (L3 + IP) → frame (L2 + MAC + FCS trailer) → bits.
  • Data units by layer: L4 segment (TCP) or datagram (UDP), L3 packet, L2 frame, L1 bits.
  • Devices by layer: hub and repeater = L1, switch and bridge = L2, router = L3. A multilayer switch and a load balancer can work at L3–L7. A next-gen firewall works up to L7.
  • Addresses by layer: port number = L4, IP = L3, MAC = L2.
  • Troubleshooting questions say "start at the bottom" or "start at the top". That means OSI layers: cable first (L1), or app first (L7).
Watch for
  • A switch is L2. If the question says "multilayer" or "L3 switch", it also routes.
  • TLS gets placed at different layers. CompTIA usually treats encryption as L6 Presentation.
  • "Which layer handles MAC addresses?" = Data link (2), not Physical (1).

Pick the right device or function for a scenario: router or switch, IDS or IPS, proxy or load balancer, NAS or SAN.

Router3Forwards packets between networks by IP"different subnets", "default gateway"

Load balancer4/7Spreads requests across servers. Health checks, TLS offload"distribute", "server farm", "high availability"
Proxy7Makes requests on a client's behalf. Caches, filters URLs"filter web access", "cache"

  • CDN (content delivery network): copies of content on servers near users, so pages load faster and the origin server carries less load.
  • VPN: an encrypted tunnel over an untrusted network. QoS: prioritizes traffic (voice/video first) when links are congested.
  • TTL means two things. In IP, a hop counter that drops by 1 at each router and discards the packet at 0, which prevents loops. In DNS, how long a record may be cached.
  • Every appliance can be physical or virtual (a VM or cloud instance). The function stays the same.
Watch for

IDS vs IPS is the classic trap. An IDS only alerts, while an IPS sits inline and can block. NAS vs SAN: file level vs block level.

Recognize each topology and the three-tier vs spine-and-leaf designs, and know which way north-south and east-west traffic flows.

Star / hub-and-spokeEverything connects to a center. Most LANs. The center is a single point of failure
MeshMany redundant links. Full mesh = every node to every node (n(n−1)/2 links)
Point-to-pointOne link between two sites
HybridA mix of topologies
North-southTraffic in or out of the data center (client ↔ internet)
East-westTraffic between servers inside the data center
Watch for

A data center with lots of server-to-server (east-west) traffic → spine and leaf. A small office that wants fewer layers → collapsed core.

For /16–/23, the same pattern happens in the third octet. Example: /20 = 255.255.240.0, block size 16 in octet 3.

  1. Find the block size
    256 − mask octet. /27 → 256−224 = 32
  2. Find the network
    The largest multiple of the block ≤ your IP octet. .77 → .64
  3. Find the broadcast
    Next network − 1. .96 − 1 = .95
  4. Find the hosts
    Network + 1 → broadcast − 1. .65–.94, 2h−2 = 30

Worked example: 192.168.10.77/27 → network 192.168.10.64, broadcast 192.168.10.95, hosts .65 – .94 (30 usable).

Explain SDN/SD-WAN, VXLAN, zero trust, SASE, infrastructure as code, and the IPv6 basics in one sentence each.

SDNSplits the control plane (decisions, centralized controller) from the data plane (forwarding). A management plane sits on top
SD-WANSoftware-managed WAN over any link (MPLS, broadband, LTE): transport agnostic, application aware, zero-touch provisioning, central policy
VXLANStretches Layer 2 across Layer 3 (MAC-in-UDP, port 4789). 16 million segments vs 4094 VLANs. Used for data center interconnect
Zero trust"Never trust, always verify." Every request is authenticated and authorized by policy, with least privilege
SASE / SSENetworking (SD-WAN) + security (SWG, CASB, ZTNA, FWaaS) delivered from the cloud. SSE = the security part only
IaCNetwork configuration as code (templates, playbooks) in version control. Prevents config drift, makes changes repeatable
IPv6Detail

  • IPv6 solves address exhaustion. To run alongside IPv4: dual stack (run both), tunneling (6to4, carry IPv6 inside IPv4), NAT64 (lets IPv6-only hosts reach IPv4).
  • Source control terms: repository, branching, conflict identification, version control. Automation terms: dynamic inventories, upgrades, drift/compliance.
Watch for

Configs slowly differ from the standard → configuration drift, fixed by IaC. "Same layer 2 network in two data centers" → VXLAN.
